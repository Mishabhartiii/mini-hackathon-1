🚗 Smart Campus Parking System
📌 About the Project
Smart Campus Parking is a simple C programming project developed for a Mini Hackathon. It helps manage parking spaces inside a college campus.
The main aim of this project is to make parking easier, save time, and reduce confusion by keeping track of available and occupied parking slots.
🎯 Objectives
•	To manage parking slots easily.
•	To check available and occupied parking spaces.
•	To park and remove vehicles.
•	To reduce the time spent searching for parking.
•	To maintain basic parking records.
⚙️ Features
1.	View Parking Slots: Displays all parking slots and their status.
2.	Park a Vehicle: Allows users to park a vehicle in an available slot.
3.	Remove a Vehicle: Allows users to remove a parked vehicle.
4.	Check Availability: Shows the number of available and occupied slots.
5.	Search Vehicle: Finds a vehicle using its vehicle number.
6.	Exit: Closes the program.
💻 Technologies Used
•	Programming Language: C
•	Compiler: GCC
•	Code Editor: Visual Studio Code
•	Platform: Windows
🧠 Concepts Used in C
This project uses the following C programming concepts:
•	Arrays: To store parking slot information.
•	Structures: To store vehicle details.
•	Pointers: To access and manage data.
•	Functions: To divide the program into smaller parts.
•	Loops: To repeat menu options.
•	Conditional Statements: To check parking availability.
▶️ How to Run the Project
1.	Download or clone this repository.
2.	Open the project folder in VS Code.
3.	Open the terminal.
4.	Compile the C program:
gcc main.c -o parking
5.	Run the program:
./parking
For Windows, you can also run:
parking.exe
